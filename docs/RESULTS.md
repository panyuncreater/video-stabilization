## 六、结论

- 合成视频：四项指标全部达标，M1 相对 M0 **无退化**（满足 M1 放行门槛）；v2.5 复跑结果与 v2.3 基本一致（S 0.8081→0.8090，单镜头素材探针零影响）。
- 实拍 test1.mp4：四项指标全部达标；v2.5 角点空间均匀化（KNOWN_ISSUES #21）治愈「修复后比原视频更抖」的感知回归——ITF 增益 +0.687→**+1.189**（逼近 M0 的 +1.299），裁剪率 0.9685（≥0.85）、S 0.9967（>0）；残余 ITF 差距归因金字塔 LK，已文档化（KNOWN_ISSUES #19）；核心模块覆盖率 98%（§11 线 ≥80%）。
- 三项遗留问题（KNOWN_ISSUES #11/#19/#20）此前已收口；v2.5 新增 #21（已解决）与 #22（非缺陷说明），KNOWN_ISSUES 无待决项。
- **M2 达成（2026-09-25）**：§11 全部 22 项验收基准通过（见第五节对照表）；requirements 6 项锁定与环境一致。剩余交付仅课程报告成稿（素材已齐）。

**规则化小结**

- [synth] 有效配置 9 个；同时达标的 5 个。
  - 稳定度最高：`gauss` w61（S=0.9673，ITF 增益 +5.422）
  - ITF 增益最高：`ma` w61（+7.658 dB，S=0.9205）
  - `ma`：S 随窗口 w15=0.6475 → w31=0.8383 → w61=0.9205；ITF 增益 w15=+2.828 → w31=+5.284 → w61=+7.658
  - `median`：S 随窗口 w15=-1.1809 → w31=-1.4977 → w61=-1.1474；ITF 增益 w15=+2.846 → w31=+5.165 → w61=+6.761
  - `gauss`：S 随窗口 w15=0.4314 → w31=0.8091 → w61=0.9673；ITF 增益 w15=+2.023 → w31=+3.098 → w61=+5.422

**判定（§11 线）：合成 S ≥ 0.5 / 裁剪率 ≥ 0.85 / D ≤ 0.05**

- `gauss` w61 稳定度最高（S=0.9673），`ma` w61 ITF 增益最高（+7.658 dB）；
- **`median` 三个窗口全部 S < 0（-1.15 ~ -1.50）——不达标**，实测证据支持 §8.4 未选它作为默认；
- 窗口越大 S 越高、ITF 增益越大，但裁剪率下降（w61 时 0.878~0.934，仍 ≥0.85）且失真 D 上升；
- 默认口径 `gauss`/w31（S=0.8091、裁剪 0.9629）在「稳定性 vs 裁剪/失真」之间取折中，窗口 61 可作更稳的选择（代价：裁剪率降至 0.9338、D 升至 0.01287）。
