## 已解决

| # | 问题 | 根因 | 解决方案 |
|---|---|---|---|
| 1 | 自研 Harris 角点定位误差约 1.4 px，不满足 §11 的 ≤1 px | 结构张量盒式滤波窗口 k=5 时响应峰偏向角点内侧 | 改 `BOX_SIZE=3`（实测峰值正落角点像素，误差 0.000 px），理由写入源码常量注释 |
| 2 | 中值平滑器偶发 `IndexError: peek from empty` 且数值与朴素实现不符 | 双堆延迟删除顺序错误：先清理堆顶再分类，会把待删堆顶移走导致分类错判与空堆 peek | 改为「先按干净堆顶分类 → 再清理」，`_value()` 增加防御性清理 |
| 3 | 镜头切分单测中「平滑运动」MAD 反而大于阈值 | 测试用例用随机噪声图构造连续帧，噪声本身 MAD 极大 | 改用平滑渐变图做连续帧、随机图做切换帧 |
| 4 | 自研 warp 与 cv2 对照时整幅错位（PSNR ≈ 9 dB） | OpenCV 5.0.0 的 `warpAffine` 改为「输入→输出」正向约定，与 ≤4 相反 | §7 注释更正；测试直接传 `M[:2]`（不再取逆） |
| 5 | `cv2.warpAffine` 抛 `M0.rows == 2 && M0.cols == 3` | 传入 3×3 齐次矩阵 | 对照调用改为 `M[:2]` |
| 6 | 合成轨迹幅度约束（帧间 ≤5 px、累积 ≤40 px）不可控，100 次重试全失败 | OU 过程单次实现的样本 std 波动极大（长记忆下有效样本仅个位数），理论 std 失效 | 改为「白噪声经高斯核平滑的增量过程 + 构造性限幅」（增量与累积分别硬限幅），首次即通过 |
| 7 | pass 2 单帧 345 ms，test1 预计 20 min | 网格逐帧重建 + float64 + warp 与 crop 两次重采样 | 输出网格缓存 + uint8 走 float32 + warp/裁剪/缩放**复合单次重采样**；提速约 1.8×（test1 pass2 ≈ 11 min） |
| 8 | 本机 CMD 中 `python -m venv` 生成的 venv 无法激活（无 activate.bat） | `python` 解析到 msys2 的 Python 3.12.11，其 venv 为 `bin/` 布局 | 用 CPython 3.13 完整路径重建标准 `Scripts/` 布局；README 增加本机备注 |
| 9 | pip 安装依赖失败（清华镜像返回空索引、官方源挂起） | 本机网络对部分 PyPI 站点不可用 | 改用阿里云镜像；README 提供镜像/代理/离线三种方案 |
| 10 | test1.mp4 裁剪率 0.786 < 0.85 | 素材为多镜头剪辑，按单镜头假设累积全局轨迹导致切换污染 | 方案①镜头切分（src/shots.py）：切换处轨迹重置、逐镜头平滑/限幅、S 逐镜头聚合 → 0.8792（M0）/ 0.981（M1） |

## 处理原则

- 任何指标不达标：**先报告数据、与用户讨论**，禁止擅自放大裁剪、降低标准或改验收线（§8.6 / §11）。
- 阈值调整（LK 残差、切换判据等）属于实现参数，§8.2 允许 ±50% 内调整，但**必须记入 PROJECT_STATE.md 决策日志**。
