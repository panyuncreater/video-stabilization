## 二、环境（与锁定档的差异）

| 项 | 本机实测 | requirements.txt 锁定 | 说明 |
|---|---|---|---|
| 操作系统 | Windows 10/11 | — | — |
| Python | 3.10.11 | ≥3.10 | 满足下限 |
| venv | 项目内 `.venv`，`--system-site-packages` | 建议标准 venv | 见下方说明 |
| numpy | **2.2.6** | 2.5.3 | ⚠ 低于锁定 |
| opencv | opencv-contrib-python **5.0.0.93**（`cv2.__version__` = 5.0.0） | opencv-python 5.0.0.93 | 同版本，包名不同 |
| matplotlib | **3.10.9** | 3.11.2 | ⚠ 低于锁定 |
| pytest / pytest-cov / coverage | **9.1.1 / 7.1.0 / 7.16.1** | 同 | ✅ 完全一致 |

**为何 numpy / matplotlib 未按锁定安装**：Python 3.10 没有 numpy 2.5.3 与 matplotlib 3.11.2 的
预编译 wheel，`pip install -r requirements.txt` 会退化为**源码编译**（实测长时间占用多核且不收敛，
最终被终止）。故本机采用 `python -m venv .venv --system-site-packages` 复用系统版本，
只补装锁定版的 pytest 三件套。
→ 影响面：**测试与指标全部通过**；`tools/verify_env.py` 因版本比对判 `exit 1`（阻塞档），
这是**环境差异而非工程缺陷**。若要完全对齐锁定档，请使用 Python ≥3.11 重建 venv。
